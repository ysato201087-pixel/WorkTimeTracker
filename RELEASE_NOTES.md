# Work Time Tracker v1.0.0

Initial distributable release.

## Highlights

- Local Windows work-time tracker
- Project creation and selection
- Start, pause, resume, and stop timer
- Paused time excluded from active work time
- Manual time entry by project
- Editable recent history, up to 10 entries per project
- Project totals recalculated from saved history
- Running or paused timer restored after restart
- Local SQLite storage
- Task tray controls
- Compact main window and separate history window

## Requirements

- Windows
- Node.js 24 or later
- Microsoft Edge or Google Chrome recommended for the app-style window

## Start

Double-click:

```text
Start-WorkTimeTracker.vbs
```

Data is created locally under `data/` and is not included in this release archive.
